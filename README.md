# Бокс

Бокс от первого лица для Android на Godot 4.4. Соперник — реалистичные видеоролики, которые переключаются по ходу боя.
Порядок: кат-сцена → бой 3 раунда по 60 секунд → кат-сцена победы или поражения.

## Как запустить

1. Скачай **Godot 4.4.x (Standard)** с godotengine.org.
2. `git clone https://github.com/maratex/box` → в Godot: **Import** → выбери `project.godot`.
3. Скопируй медиа в `assets/media/` (см. ниже) и нажми **F5**.

## Управление

| Действие | Экран | Клавиатура |
|---|---|---|
| Уклон влево / вправо | ◀ ▶ слева внизу | A / D |
| Блок (держать) | БЛОК | Пробел |
| Удар левой / правой | ЛЕВЫЙ / ПРАВЫЙ справа | J / K |
| В меню | кнопка «Назад» | Esc |

Как драться:
- **Уклоняйся или закрывайся**, когда соперник замахивается. Джеб уходит уклоном в любую сторону, хук — только **вправо** (он летит слева).
- **Бей на его замахе** — контратака ×1,5, удар соперника срывается.
- **Бей сразу после его удара** — он открыт и не успевает закрыться.
- В стойке он часто блокирует. Удары и уклоны тратят выносливость.

## Медиа

Медиа не хранятся в репозитории — они на Google Диске. Положи их сюда:

```
assets/media/photos/  opponent_base.jpg   — кадр стойки соперника (меню, кат-сцена, заставка)
                      enemy_portrait.png  — портрет у полосы здоровья
                      gloves_guard.png, gloves_jab.png, gloves_cross.png, gloves_block.png
                                          — свои перчатки, PNG с прозрачным фоном (необязательно)
assets/media/video/   idle.ogv            — стойка, крутится по кругу
                      jab.ogv, cross.ogv, hook.ogv          — атаки соперника
                      block.ogv, hit_head.ogv, hit_hook.ogv, hit_body.ogv, knockdown.ogv
                      intro.ogv, faceoff.ogv, win.ogv, lose.ogv  — кат-сцены
```

Любого ролика может не быть — игра использует то, что есть. Пока нет роликов «пропустил удар», соперника просто отбрасывает назад.

Тайминги роликов (длина, момент удара, урон, куда уклоняться) задаются в `scripts/game.gd`, таблица `CLIPS`.
Если ролик заменили, поправь там `length` и `impact`.

**Godot воспроизводит только `.ogv` (Theora).** MP4 конвертирует `tools/convert_videos.bat` (Windows, нужен ffmpeg: `winget install ffmpeg`) или `tools/convert_videos.sh`.

## Сборка APK

1. В Godot: **Editor → Manage Export Templates → Download and Install**.
2. Установи Android Studio (или только Android SDK) и JDK 17. В **Editor → Editor Settings → Export → Android** укажи пути к SDK и JDK.
3. **Project → Export → Android** (пресет уже есть) → **Export Project** → `build/box.apk`.
4. Скопируй APK на телефон и установи (разреши установку из неизвестных источников).

## Устройство проекта

| Файл | Что делает |
|---|---|
| `scripts/game.gd` | Порядок экранов, кат-сцены, **таблица роликов соперника `CLIPS`**, имена, клавиши |
| `scripts/fight.gd` | Бой: раунды, удары, уклоны, блок, попадания, эффекты камеры, ИИ соперника |
| `scripts/opponent.gd` | Соперник из видео: стойка по кругу и ролики действий поверх с плавным переходом |
| `scripts/fighter.gd` | Здоровье и выносливость |
| `scripts/hud.gd` | Полосы здоровья и выносливости, портреты, таймер |
| `scripts/cutscene.gd` | Кат-сцены: видео / картинка / текст, пропуск касанием |
| `scripts/touch_pad.gd` | Экранные кнопки с мультитачем |
