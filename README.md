# Бокс

Боксёрский поединок для Android на Godot 4.4: кат-сцена → бой 3 раунда по 60 секунд → кат-сцена победы или поражения.

## Как запустить

1. Скачай **Godot 4.4.x (Standard)** с godotengine.org.
2. `git clone https://github.com/maratex/box` → в Godot: **Import** → выбери `project.godot`.
3. **F5** — игра запускается на компьютере. Управление мышью (нажатие на экранные кнопки) или с клавиатуры.

Без фото и видео игра тоже работает: вместо них заглушки.

## Управление

| Действие | Экран | Клавиатура |
|---|---|---|
| Шаг влево / вправо | ◀ ▶ слева | A / D |
| Уклон | УКЛОН | Shift или W |
| Джеб (быстрый, слабый) | ДЖЕБ | J |
| Кросс (средний) | КРОСС | K |
| Хук (медленный, сильный, ближняя дистанция) | ХУК | L |
| Блок (держать) | БЛОК | Пробел или S |
| В меню | кнопка «Назад» | Esc |

Механика: удары тратят выносливость, уставший боксёр бьёт слабее. Удар в момент замаха соперника — **контратака ×1,5**. Блок срезает урон, но тратит выносливость; если она закончится, блок пробит. Победа нокаутом или решением судей после 3 раундов.

## Фото и видео

Медиа не хранятся в репозитории, они лежат на Google Диске. Перед запуском скопируй их сюда:

```
assets/media/photos/   player_portrait.png, enemy_portrait.png, faceoff.png,
                       ring_bg.png, locker_bg.png, win.png, lose.png
assets/media/video/    intro.ogv, faceoff.ogv, win.ogv, lose.ogv
```

Любого файла может не быть, тогда игра подставит замену: видео → картинка с медленным наездом → тёмный фон с текстом.

**Важно: Godot воспроизводит только видео в формате `.ogv` (Theora), MP4 он не откроет.** Сгенерированные MP4 сконвертируй скриптом:

- Windows: положи MP4 в `assets/media/video/` и запусти `tools\convert_videos.bat` (нужен ffmpeg: `winget install ffmpeg`)
- Linux/Mac: `tools/convert_videos.sh`

## Сборка APK

1. В Godot: **Editor → Manage Export Templates → Download and Install**.
2. Установи Android Studio (или только Android SDK) и JDK 17. В **Editor → Editor Settings → Export → Android** укажи пути к SDK и JDK.
3. **Project → Export → Android** (пресет уже есть) → **Export Project** → `build/box.apk`.
4. Скопируй APK на телефон и установи (разреши установку из неизвестных источников).

## Устройство проекта

| Файл | Что делает |
|---|---|
| `scripts/game.gd` | Глобальное: порядок экранов, список кат-сцен и их тексты, загрузка медиа, имена боксёров |
| `scripts/fight.gd` | Бой: раунды, таймер, попадания, нокаут, решение судей, экранные кнопки |
| `scripts/boxer.gd` | Боксёр: удары (урон, скорость, дальность в `PUNCHES`), блок, уклон, рисовка |
| `scripts/enemy_ai.gd` | ИИ соперника: `reaction`, `aggression`, `think_interval` — сложность |
| `scripts/hud.gd` | Шкалы здоровья и выносливости, портреты, таймер |
| `scripts/cutscene.gd` | Кат-сцены: видео / картинка / текст, пропуск касанием |
| `scripts/ring.gd` | Фон ринга (картинка или нарисованный кодом) |
| `scripts/touch_pad.gd` | Экранные кнопки с мультитачем |
